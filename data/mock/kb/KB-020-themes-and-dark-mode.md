id: KB-020
title: Themes and dark mode (Settings > Appearance)
---
Go to Settings > Appearance to choose a theme. The available options are Light, Dark, and
System Default.

The Dark theme is being rolled out gradually to Pro and Enterprise accounts. Until it is enabled for
your account, only Light and System Default are shown. Support can request early access for you.

Known issue (BUG-4821): in the CRM macOS desktop app version 4.1.2 and earlier, System Default does not
follow the macOS dark appearance and the app stays light. This is fixed in version 4.1.3. Update via
the app menu > Check for Updates. As a workaround, the web app follows System Default correctly.

Scheduled theme switching (for example, switching to dark at a set time) is not supported yet.
