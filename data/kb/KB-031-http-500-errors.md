id: KB-031
title: Troubleshooting HTTP 500 errors
---
An HTTP 500 error means the server failed to process the request.

If only one user is affected, clear the browser cache, try a private window, and disable browser
extensions. If several users, browsers, or devices see the error at the same time, the problem is
almost certainly on our side. Please report it to support right away with your workspace ID and
region. Enterprise customers should use the priority support line.
