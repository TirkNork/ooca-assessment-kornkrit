How to read this
Labels
Urgency and action list every acceptable value. Issue types, products, required risk flags, KB articles and tools must all appear; extra ones are not penalised. Optional risk flags are defensible either way.
Runs
Each ticket is triaged several times with the real model, so consistency can be measured.
Not scored
The wording of suggested replies and handoff summaries; that needs human review or an LLM judge.
